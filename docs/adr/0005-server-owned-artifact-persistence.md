# 由后端 API 负责 Artifact 持久化

Qijian AI Design 的 Artifact 状态由后端 API 负责保存和读取，浏览器不作为项目事实来源。这样可以让项目在刷新、换设备和多人协作时保持一致，并为后续权限、文件存储和 skill 调用提供稳定边界；前端可以保留缓存，但缓存只能加速访问，不能取代服务端状态。

**Status:** accepted

**Consequences**

- 下一阶段需要同时搭建 API、数据库和前端数据访问层。
- 项目状态必须通过 API 进行版本化写入，禁止组件直接修改共享状态文件。
- 本地开发需要一个可重复启动的数据库环境。
