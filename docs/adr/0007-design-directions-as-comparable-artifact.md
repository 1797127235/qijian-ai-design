# 设计方向集作为可比较的 Artifact

方向生成阶段产出一个 `design_directions` Artifact。一个版本包含完整的三张方向卡，而不是为每张卡建立互不关联的结果记录。这样模型可以在同一上下文中拉开方向差异，平台也能在版本审阅时同时比较它们。

**Status:** accepted

## 输入边界

生成任务唯一读取已确认的项目理解版本。该版本通过 `input_refs` 引用原始户型图或 CAD 图纸；原始图纸作为不可变的空间与几何事实参考。参考图输入只影响视觉语言，不得改变墙体、门窗、开口、尺寸或主要动线。

方向卡生成不读取未确认草稿，也不把效果图作为第一版输出。卡片中的材料、家具和灯具只使用设计语言级描述，不虚构品牌、型号、价格或资产 ID。

## 方向差异

三张卡必须在空间组织策略和关键取舍上不同，而不是仅替换名称或视觉风格。机械校验检查字段完整性、方向差异、已确认硬约束和禁止动作；系统不生成或展示 AI 置信度。

## 版本与编辑

- 初次生成创建 `draft` 版本；
- 设计师编辑或单卡重生成时追加新版本，不覆盖旧版本；
- 单卡重生成保留另外两张卡，并替换指定卡片；
- 设计师选择一个方向后追加 `confirmed` 版本，并记录选择的卡片 ID；
- 方向集生成失败时保留失败任务和历史版本，重试创建新任务；不得使用静态内容填充失败状态。

## 未纳入本 ADR 的内容

方向集第一版不生成效果图，也不声称已经完成几何一致性验证。效果图生成及其几何检查属于后续阶段。
