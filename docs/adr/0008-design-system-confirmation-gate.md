# 方向确认后先生成方案约束包

设计师确认一个方向后，系统先生成 `design_system` 方案约束包，再进入效果图生成。方案约束包是后续多空间图像和提案内容共享的设计基线，避免每次生成重新解释方向而产生漂移。

**Status:** superseded by [单画布 Agent 后端重写](../implementation/agent-backend-redesign.md)

当前实现已移除 `design_system` Artifact。本文保留为历史决策记录，不描述现行产品流程。

## 约束包内容

`design_system` 至少包含：

- 已确认的空间关系和不可变几何政策；
- 方向概念和空间策略；
- 色彩调色板与材料类别；
- 家具、灯具和软装语言；
- 光线与时间设定；
- 禁止出现的元素；
- 方向卡、Brief、项目理解版本和参考图输入的来源关联。

## 确认与编辑

约束包由设计师检查后确认。设计师可以编辑概念、策略、材料、色彩、家具、灯光、禁止元素和各空间应用说明；每次编辑追加新的草稿版本，确认后才可作为效果图输入。原始 CAD 几何和项目理解中的硬约束不能被约束包静默改写。

## 几何声明

方向卡和方案约束包阶段只声明“保持来源几何”，不显示“几何已通过”之类的结论。真正的图像几何一致性检查在效果图生成阶段单独完成。
